01 / FOUNDATIONS

One subproblem, one computation

A recursive solution may reach the same subproblem through different branches. Dynamic programming saves that answer and reuses it. The key design task is choosing a state that contains everything needed to solve the remaining problem.

Two ideas to look for

Overlapping subproblems: the same smaller problem appears repeatedly.

Optimal substructure: for an optimization problem, an optimal solution can be built from optimal solutions to suitable subproblems. Counting problems such as Fibonacci and binomial coefficients also use DP, without minimizing or maximizing an objective.

A reusable design process

  1. State: what exactly does one table entry mean?
  2. Recurrence: which smaller states determine it?
  3. Base cases: where does the computation start?
  4. Evaluation: choose an order that respects dependencies, or use memoization.
  5. Reconstruction: recover a solution, if the problem asks for more than its value.
  6. Complexity: count states and work per state; include reconstruction.
02 / REPEATED WORK

Fibonacci: recursion to reuse

Let F(n) be the nth Fibonacci number. Direct recursion computes both predecessors at every non-base call. In the recursion tree for F(5), for example, F(3) appears twice and F(2) three times.

F(0) = 0, F(1) = 1
F(n) = F(n−1) + F(n−2), for n ≥ 2

How much work is repeated?

Bottom-up: start with the base cases

Fib(n):
    if n == 0: return 0
    F[0] = 0; F[1] = 1
    for i = 2 to n:
        F[i] = F[i−1] + F[i−2]
    return F[n]

Top-down: remember recursive results

memo = empty map
Fib(k):
    if k ≤ 1: return k
    if k is in memo: return memo[k]
    memo[k] = Fib(k−1) + Fib(k−2)
    return memo[k]

Naive recursion: Θ(φⁿ) time, where φ ≈ 1.618, and O(n) stack space. Both DP versions: O(n) time and O(n) space, counting arithmetic operations as constant time. Bottom-up needs only the two previous values, so its auxiliary space can be O(1). Large-integer arithmetic adds a cost as n grows.

Why is the bottom-up result correct?

The base cases are correct by definition. Assume all earlier entries are correct. The recurrence adds the two correct preceding Fibonacci values, so the next entry is correct. Induction establishes every entry through F(n).

03 / COUNTING

Binomial coefficients

C(n,k) counts the ways to choose k items from n distinct items, ignoring order. Choose one distinguished item: a selection either includes it, leaving k−1 choices among n−1 items, or excludes it, leaving k choices among n−1 items. These two disjoint cases cover every selection.

C(n,0) = C(n,n) = 1
C(n,k) = C(n−1,k−1) + C(n−1,k), for 0 < k < n

For five items A, B, C, D, E, the ten pairs are AB, AC, AD, AE, BC, BD, BE, CD, CE, DE. Thus C(5,2) = 10.

Build Pascal's triangle

for i = 0 to n:
    for j = 0 to min(i,k):
        if j == 0 or j == i: B[i,j] = 1
        else: B[i,j] = B[i−1,j−1] + B[i−1,j]
return B[n,k]

O(nk) time and space for k ≥ 1; including k = 0, the loop bound is O((n+1)(k+1)). Each cell uses the previous row, so row-by-row evaluation is valid. A one-dimensional version must update from right to left to preserve previous-row values.

04 / A ONE-DIMENSIONAL STATE

Maximum contiguous subarray

Given a nonempty array, find a nonempty, contiguous subarray of maximum sum. The best subarray ending at position i either extends the best one ending at i−1, or starts at i.

H[1] = A[1]
H[i] = max(A[i], H[i−1] + A[i])
answer = max H[i]

Extend or start again?

best = current = A[1]
start = end = currentStart = 1
for i = 2 to n:
    if current < 0:
        current = A[i]; currentStart = i
    else: current = current + A[i]
    if current > best:
        best = current; start = currentStart; end = i
return best, start, end

O(n) time, O(1) auxiliary space when only the current sum, best sum, and indices are kept. The explorer retains a trace for learning. Initializing from A[1], rather than zero, handles all-negative arrays. On a tie, this implementation keeps the earlier solution it already found.

Why does one state per ending position suffice?

Any subarray ending at i is either the single element A[i], or a subarray ending at i−1 extended by A[i]. Of all extensions, the best uses H[i−1]. Taking the maximum over all ending positions covers every nonempty subarray.

05 / TWO CHOICES PER ITEM

0/1 Knapsack: skip or take

Each item has a positive integer weight and a value; take each item at most once. Maximize total value without exceeding capacity C. Unlike fractional knapsack, taking the highest value-to-weight ratio first is not guaranteed to solve this problem.

State: T[i,B] is the maximum value attainable using only the first i items and capacity B.

T[0,B] = 0; T[i,0] = 0
if w[i] > B: T[i,B] = T[i−1,B]
otherwise: T[i,B] = max(T[i−1,B], v[i] + T[i−1,B−w[i]])

Pack first. Then inspect the decisions.

Lecture example: capacity 15. Click items to build a packing, then compare it with the DP optimum.

Compute the table

Dark cell: current calculation. Green cells: dependencies. Outlined cells show reconstruction.

for B = 0 to C: T[0,B] = 0
for i = 1 to n:
    T[i,0] = 0
    for B = 1 to C:
        T[i,B] = T[i−1,B]
        if w[i] ≤ B:
            T[i,B] = max(T[i,B], v[i] + T[i−1,B−w[i]])
return T[n,C]
Why is the recurrence correct?

Every feasible solution either excludes item i or includes it. Excluding it leaves a solution among the first i−1 items with capacity B. Including it contributes v[i] and leaves capacity B−w[i] among the first i−1 items. A better solution to the remaining subproblem would improve the whole packing, so an optimum uses an optimal remaining packing.

How do we reconstruct the items?

Start at T[n,C]. If T[i,B] equals T[i−1,B], skipping i preserves an optimal value. Otherwise take i and reduce B by w[i]. Decrease i in either case. Ties may permit more than one optimal packing; skipping on equality returns one of them. In this example the selected items are G2, G3, G4, G6: weight 15, value 26.

Why “pseudopolynomial”?

The table takes O(nC) time and space, with O(n) reconstruction. C is a numeric value, while writing it in binary takes Θ(log C) bits. Thus O(nC) is not a polynomial bound in the encoded input length. Value-only DP can use O(C) space by scanning capacities downward for each item.

06 / CHOOSING A SPLIT

Matrix-chain multiplication

Matrix multiplication is associative: parenthesization changes the amount of work, while preserving the result and the matrix order. Multiplying a p×q matrix by a q×r matrix costs pqr scalar multiplications in the standard algorithm.

State: m[i,j] is the minimum scalar-multiplication cost for matrices Mi through Mj, where Mi has dimensions d[i−1] × d[i].

m[i,i] = 0
m[i,j] = min over i ≤ k < j of:
m[i,k] + m[k+1,j] + d[i−1] · d[k] · d[j]

Compare the possible final splits

Lecture example: M1 = 2×5, M2 = 5×3, M3 = 3×4.

for i = 1 to n: m[i,i] = 0
for len = 2 to n:
    for i = 1 to n−len+1:
        j = i+len−1; m[i,j] = ∞
        for k = i to j−1:
            q = m[i,k] + m[k+1,j] + d[i−1]*d[k]*d[j]
            if q < m[i,j]: m[i,j] = q; S[i,j] = k

O(n²) states, O(n) candidate splits per state: O(n³) time and O(n²) space. Fill by increasing chain length. Recover the parenthesization by recursively following S; the reconstruction tree has O(n) nodes.

Worked comparison and correctness

M1(M2M3) costs 5×3×4 + 2×5×4 = 100. (M1M2)M3 costs 2×5×3 + 2×3×4 = 54. Every full parenthesization has a final split k. For that split, its two subchains must themselves be optimal; otherwise replacing one improves the total. Trying all splits therefore finds an optimum.

07 / VALUE AND WITNESS

Longest common subsequence

A subsequence preserves character order but may skip characters. Find a longest subsequence common to two strings. Its characters need not be contiguous.

State: f[i,j] is the LCS length of the first i characters of X and the first j characters of Y.

f[0,j] = f[i,0] = 0
if X[i−1] == Y[j−1]: f[i,j] = 1 + f[i−1,j−1]
otherwise: f[i,j] = max(f[i−1,j], f[i,j−1])

Find the length. Recover a sequence.

for i = 0 to n: f[i,0] = 0
for j = 0 to m: f[0,j] = 0
for i = 1 to n:
    for j = 1 to m:
        if X[i−1] == Y[j−1]: f[i,j] = 1 + f[i−1,j−1]
        else: f[i,j] = max(f[i−1,j], f[i,j−1])
Why does the recurrence cover every case?

If the final characters match, an LCS can end with that character; removing it leaves an LCS of the two shorter prefixes. If the final characters differ, a common subsequence must omit at least one of them. Taking the better of the two shorter-prefix states covers those alternatives.

Reconstruct without copying the answer repeatedly
characters = empty list; i = n; j = m
while i > 0 and j > 0:
    if X[i−1] == Y[j−1]:
        append X[i−1] to characters
        i = i−1; j = j−1
    else if f[i−1,j] ≥ f[i,j−1]: i = i−1
    else: j = j−1
reverse characters; return join(characters)

Following ties upward returns one optimal subsequence. Another tie choice may produce a different equally long answer.

O(nm) time and space for nonempty strings; including empty strings, the allocated table has (n+1)(m+1) cells. Backtracking takes O(n+m) time when collecting characters and reversing once. Two rows suffice for the length alone; retaining the full table supports this reconstruction.

08 / TRANSFER

Design a DP solution yourself

Minimum-cost staircase. Start at step 0. Each move climbs one or two steps. Entering step i costs c[i]; step 0 is free. Reach step n with minimum total cost. The final step's cost must be paid.

  1. Define a state precisely.
  2. Give the recurrence and base cases.
  3. Choose a valid evaluation order.
  4. Compute the minimum cost and recover a path.
  5. Analyze time and space. What changes if only the cost is required?

Hint 1 · Choose a state

Let D[i] be the minimum total cost of reaching step i, including the cost of entering i.

Hint 2 · Look at the last move

The previous step is either i−1 or i−2. Reaching the cheaper predecessor is enough once the last move is fixed.

Worked solution
D[0] = 0; D[1] = c[1]
D[i] = c[i] + min(D[i−1], D[i−2]), for i ≥ 2
D[0..5] = [0, 2, 3, 6, 4, 9]

The minimum is 9 along 0 → 2 → 4 → 5. Save a minimizing predecessor to reconstruct a path. O(n) time, O(n) space with reconstruction; O(1) auxiliary space for the value alone. For n = 0, return 0.
